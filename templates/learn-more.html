How ScoreForecast Works

Follow these simple steps to use the prediction system

1

Sign Up / Login

First create an account using the Sign Up page. If you already have an account, simply Login to access the ScoreForecast system.

2

Select Student or Teacher

After logging in, choose your role. If you are a Student, click the Student button to access prediction features. If you are a Teacher, click the Teacher button to analyze student datasets and view prediction insights.

3

Choose Prediction

Students can select Next Semester Prediction or Final Semester Prediction. Enter the required academic details to generate a predicted score. Teachers can upload datasets and analyze student performance.
